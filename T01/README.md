# T01 — Coneixent la competència i el sector

## Descripció breu
Anàlisi del sector dels serveis informàtics a Mataró/Maresme i identificació de la competència.

## Contingut de la tasca
- Recerca de 3 empreses del sector.
- Classificació per mida i serveis.
- Creació d’un organigrama amb PlantUML / UMLTree.
- Definició de departaments i funcions.
- Proposta d’estratègia competitiva.
- Recursos humans necessaris.

## Lliurables
- Document complet amb totes les fases.
- Organigrama en codi.
- Justificació de decisions.
