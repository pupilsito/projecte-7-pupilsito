# T03 — Servidor de fitxers

## Descripció breu
Implementació d’un servidor de fitxers amb permisos, quotes i filtratge.

## Contingut de la tasca
- Creació de grups a Active Directory.
- Compartició de carpetes amb:
  - Explorador
  - Server Manager
  - PowerShell
- Configuració de quotes NTFS i FSRM.
- Filtrat d’arxius.
- Proves d’accés i auditoria.
