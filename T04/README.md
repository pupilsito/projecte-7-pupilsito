# T04 — Servidor d’impressió

## Descripció breu
Configuració d’un servidor d’impressió amb Printer Pooling i desplegament via GPO.

## Contingut de la tasca
- Instal·lació de dues impressores PDF24.
- Configuració del rol Print and Document Services.
- Activació del Printer Pooling.
- Desplegament automàtic amb GPO.
- Prova de càrrega i configuració d’horaris.
